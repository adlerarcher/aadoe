# Hackathons

Timed sprints on geothermal and subsurface permitting. Partnership of CEQ PIC and Pacific Northwest National Laboratory.

Nested on the AADOE hub at `/gpic/`.

Rebuild pages from `scripts/build-pages.py`.

## Serve this site

Requires Node 20 or later.

```
npm run dev
```

Opens the hackathons home at `http://localhost:5175`.
